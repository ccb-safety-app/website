Holiday card address labels from a Google Sheet

Holiday cards are the biggest mailing most households do all year. The US Postal Service counted more than 1.3 billion holiday cards mailed in a single year, and handwriting the envelopes is the slow part. Keeping the list in a Google Sheet means you build it once and reuse it every year.

1. Build the list once

  1. Make a sheet with these titles in row 1: Name, Address 1, Address 2, City, State, Zip, Country, Send this year.
  2. Write the name the way it should appear on the envelope, for example "The Raman Family" or "Priya and Sam Raman".
  3. Add a Send this year column with a checkbox (Insert → Checkbox) or Yes/No, so you can skip people without deleting them.
  4. Leave Country empty for domestic addresses and fill it in only for addresses abroad.

2. Collect missing addresses

For people who have moved, send a short Google Form with the same fields and copy the answers into your sheet. Asking in early November leaves time for replies.

3. Check the addresses

A typo in a street name or zip code means a card comes back weeks later. Label Maker's Check addresses looks up each address with Google Maps and suggests corrections; nothing changes unless you accept a suggestion. At minimum, sort by Zip and look for codes with four digits: that usually means a leading zero was dropped (format the Zip column as plain text to stop it happening).

4. Print the labels

  1. Use Avery 5160 (30 per sheet) for recipients, or Avery 5163 (2" × 4") if you want a larger, more formal label.
  2. Print only the people you're sending to: in Label Maker, open Rows to print, choose Only rows where a column has a tick or text and pick Send this year. Unticked boxes, No and empty cells are skipped.
  3. Print a test page on plain paper at 100% and hold it against a label sheet before printing the real labels.
  4. For return labels, print one full sheet of your own address on Avery 5167 (80 per sheet). See Return address labels from Google Sheets.

5. Prefer printed envelopes?

If your printer feeds envelopes well, print straight onto them instead. See How to print envelopes from Google Sheets.

6. Next year in five minutes

Keep the sheet. Next year, update a few addresses, reset Send this year, and print again. Label Maker remembers your label sheet, and the layout and row choices for each spreadsheet.
