Avery 5160 template for Google Docs: how to build one

Google Docs has no built-in label templates, but a table with the right measurements prints onto Avery 5160 sheets. Building it takes about ten minutes. Typing 30 addresses into it by hand takes longer, so the end of this guide covers filling it from a spreadsheet.

1. Set the page

  1. Open a new Google Doc and click File → Page setup.
  2. Paper size: Letter (8.5" × 11"), orientation Portrait.
  3. Margins (inches): top 0.5, bottom 0.5, left 0.19, right 0.19. Click OK.

2. Insert the table

Avery 5160 has a 1/8" gap between its three columns, so the table needs five columns: label, gap, label, gap, label.

  1. Click Insert → Table and choose 5 × 10 (5 columns, 10 rows).
  2. Select the whole table, right-click and choose Table properties.
  3. Under Columns, set widths (select each column in turn): 2.62, 0.13, 2.62, 0.13, 2.62 inches. These are the label widths (2-5/8") and gaps (1/8") rounded to two decimals so they add up to the 8.12" between the margins.
  4. Under Rows, set the minimum row height to 1 inch.
  5. Under Cell, set padding to 0.05 inch, and set the table border to 0 pt so no lines print.

3. Keep it on one page

Ten rows of 1" fill the page exactly, and Google Docs always keeps an empty line after a table. If a blank second page appears, click that empty line below the table, set its font size to 1 and its line spacing to Single. Text that is too big for a cell also makes the row grow, so keep addresses to four lines at about 10 pt.

4. Fill it with addresses

Type or paste each address into columns 1, 3 and 5, leaving the gap columns empty. For more than a page, copying 30 addresses at a time from a spreadsheet gets slow and it's easy to skip someone.

The faster route is to keep the list in Google Sheets and let a tool build the document. Label Maker creates the same layout from your sheet in one click, adds more pages as needed, and skips empty address lines. See How to print Avery 5160 labels from Google Sheets.

5. Test before you use the labels

Print one page on plain paper at Actual size / 100%, hold it against a label sheet in front of a light, and check every address sits inside its label. Google Docs rounds column widths, so the right-hand column can drift by a millimetre or so; that's normal and still inside the label.
