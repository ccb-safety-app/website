# northpineapps.com

The Northpine Apps website (Label Maker for Google Sheets).

- Edit pages in `src/` (`index.html`, `privacy.html`, `terms.html`) and styles in `src/style.css`.
- Images live in `assets/`.
- Run `python3 build.py` to rebuild. The published site is the `docs/` folder (GitHub Pages: branch `main`, folder `/docs`), served at https://northpineapps.com.
