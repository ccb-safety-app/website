How to print Avery 5160 labels from Google Sheets

Avery 5160 is the standard US address label: 30 labels on a letter-size sheet. Google Sheets can't print onto it directly, because it prints a grid of cells, not label-sized boxes. Here are the two ways that work, and how to make sure the print lines up.

Avery 5160 measurements

These are the numbers any template or add-on needs to match. The same layout fits Avery 8160, 5260 and 18160.

SheetUS Letter, 8-1/2" × 11"
Labels per sheet30 (3 across, 10 down)
Label size2-5/8" × 1"
Top and bottom margin1/2"
Left and right margin3/16" (0.1875")
Gap between columns1/8" (0.125")
Gap between rowsNone

Step 1: get your sheet ready

  1. Put one person per row, with titles in row 1: First Name, Last Name, Address 1, Address 2, City, State, Zip.
  2. Format the Zip column as plain text (Format → Number → Plain text) so zip codes that start with 0, like 02903, keep their leading zero.
  3. Leave Address 2 empty when there's no apartment or suite. A good label tool skips the empty line instead of leaving a gap.

Step 2, option A: use Spreadsheet Labels (fastest)

  1. Open your sheet and click Extensions → Spreadsheet Labels → Create labels.
  2. Choose Avery 5160 / 8160. Spreadsheet Labels finds the name and address columns for you and shows a preview of each label.
  3. Click Create labels. You get a Google Doc and a PDF laid out to the measurements above.

It also handles the awkward cases: starting on a partly used sheet, printing several copies of each label, and shifting the print if your printer is slightly off.

Step 2, option B: free, with Avery's own website

  1. In Google Sheets, click File → Download → Comma-separated values (.csv).
  2. Go to Avery's free Design & Print Online, choose product 5160, pick a design and use its mail-merge option to import the CSV file.
  3. Download the PDF it makes.

This works well for a one-off job. The trade-off is that your list leaves Google Sheets, so any change means downloading and uploading again.

Step 3: print so it lines up

  1. Open the PDF and print one page on plain paper first.
  2. In the print window, set the scale to Actual size or 100%. "Fit to page" shrinks the page and every label drifts.
  3. Hold the test page against a label sheet in front of a window or lamp. If the text sits inside every label, print on the labels.
  4. If everything is off by the same amount, your printer is shifting the page. Move the layout the opposite way (Spreadsheet Labels has a Printer alignment setting for this), then test again.

Feed label sheets one at a time if your printer tends to grab two, and use the tray your printer manual recommends for labels.
