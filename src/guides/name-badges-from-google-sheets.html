Print name badges from a Google Sheet

Conferences, open houses, workshops and first days of school all need name badges, and the attendee list is usually already in a sheet or comes from a Google Form. Here's how to print the whole stack at once, so nobody writes badges by hand at the door.

{{INSTALL_STRIP:label-maker}}

1. Get the list into a sheet

  1. If people signed up with a Google Form, open the form's Responses tab and click Link to Sheets. The answers become a spreadsheet.
  2. Make sure there's a Name column with the name as people want it shown ("Priya Raman", not "RAMAN, PRIYA") and a second column such as Company, Role or Table.

2. Use name badge sheets

Avery 5395 (and 8395) are adhesive name badges, 3-3/8" × 2-1/3", 8 per sheet. Choose it in Choose Your Label Sheet by typing 5395. For a different badge size, use Add Your Own Size and enter the measurements from the package.

3. Make the name the biggest thing

  1. Build two lines: Name on the first, Company or Role on the second.
  2. In Text Style, choose Centered and turn on Bold First Line.
  3. Set a large size (for example 20–24 pt). Long names are shrunk automatically until they fit, and the preview shows every badge before you print.
  4. Optional: Pictures and Codes → The Same Picture on Every Label for your event logo, or A Different Picture for Each Row if a column holds photo links.
  5. Optional: a QR Code from a column of links (a profile page or a session schedule), so people can scan each other's badges.

4. Print and check

  1. Print one page on plain paper at Actual size (100%) and hold it against a badge sheet.
  2. Late sign-ups? Select just their rows and choose Rows to Print → Only the rows I select in the sheet, and use Start Position to fill the empty badges on a partly used sheet.
