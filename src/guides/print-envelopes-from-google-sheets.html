How to print envelopes from Google Sheets

Printing straight onto envelopes looks better than labels for invitations and letters. It needs a document with one envelope-sized page per address, and a printer set up to feed envelopes.

Common envelope sizes

EnvelopeSizeTypical use
#109-1/2" × 4-1/8"Business letters, bills
#98-7/8" × 3-7/8"Reply envelopes
A77-1/4" × 5-1/4"Invitations, 5" × 7" cards
DL220 × 110 mmInternational letters (A4 folded in three)
C5229 × 162 mmA5 cards, A4 folded once
C6162 × 114 mmA6 cards, postcards

Measure your envelope if you aren't sure: greeting card envelopes are often A7 or A2 rather than a business size.

Make the envelope document

  1. Keep your list in Google Sheets with Name, Address 1, Address 2, City, State and Zip columns.
  2. In Label Maker, choose the envelope size under Choose label sheet (filter Use by Envelope).
  3. Add your return address once; it prints in the top-left corner of every envelope. Leave it empty if your envelopes already have one printed.
  4. Click Create labels. You get one landscape page per address, with the recipient placed where the post office expects it.

Without an add-on, Google Docs can do one envelope at a time: set File → Page setup to a custom size matching the envelope, landscape, and type the address in a text box. That's fine for a handful, slow for fifty.

Set up the printer

  1. Check your printer's manual for which way envelopes go in (flap up or down, left or right edge first). Most home printers take envelopes in the rear or manual feed tray.
  2. In the print window, choose the envelope size as the paper size and set the scale to Actual size / 100%.
  3. Print the first envelope on a sheet of paper cut to the same size, or on one spare envelope, before printing the rest.

If the address lands in the wrong place, the most common cause is the printer treating the envelope as letter paper. Setting the paper size in the print window usually fixes it.

When labels are the better choice

Thick, padded or textured envelopes jam many printers. For those, print on Avery 5160 address labels instead and stick them on.
