Print shipping labels from a Google Sheet of orders

If you sell handmade goods, run a small online shop or send out school or club orders, the order list probably already lives in a spreadsheet. This guide turns today's orders into shipping address labels in a few minutes, with your logo on each one.

{{INSTALL_STRIP:label-maker}}

These are address labels. Postage still comes from your carrier: buy it online or at the counter and add it to the package separately.

1. Keep orders in one sheet

  1. Use titles like Order, Name, Address 1, Address 2, City, State, Zip, Country, Items, Ship Today in row 1.
  2. Paste or export new orders into the sheet. Most shop platforms can export orders as a CSV file that opens in Google Sheets.
  3. Add a Ship Today checkbox column (Insert → Checkbox) and tick the orders that are packed.

2. Choose a shipping label size

  • Avery 5163: 4" × 2", 10 per sheet. Fits padded mailers and small boxes.
  • Avery 5164: 4" × 3-1/3", 6 per sheet. Room for a logo and a larger address.
  • Avery 5168: 3-1/2" × 5", 4 per sheet. Big and easy to read on boxes.

Using a different brand? Choose Add Your Own Size and type the label size and layout from the box.

3. Add your logo and an order code

In Spreadsheet Labels, open Pictures and Codes:

  1. Choose The Same Picture on Every Label and upload your shop logo.
  2. Optionally add a QR Code or Barcode (Code 128) from the Order column, so you can scan which order a returned package belongs to.

Then click the columns to build the label: Name on the first line, the address lines below. Turn on UPPERCASE (postal style) in Text Style if you like the post-office look.

4. Print only today's orders

  1. Open Rows to Print → Only rows where a column has a tick or text → Ship Today.
  2. An order with several boxes? Open Copies → Take the Number from a Column and point it at a "Boxes" column.
  3. Partly used sheet left from yesterday? Use Start Position to begin on the first empty label.
  4. Print a test page at Actual size (100%) on plain paper first, then the labels.

When the packages are out, untick Ship Today (or add a Shipped date) so tomorrow's print only has new orders.
