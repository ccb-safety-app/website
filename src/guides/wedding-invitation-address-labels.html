Wedding invitation address labels from a Google Sheet

Most couples already keep the guest list in a spreadsheet, because it's shared with family and changes every week. The same sheet can print the address labels for save-the-dates, invitations and thank-you cards, so nobody copies addresses by hand three times.

1. Set up the guest list

  1. Put these titles in row 1: Envelope Name, Address 1, Address 2, City, State, Zip, Country, Save the Date, Invitation, Thank You.
  2. Write Envelope Name exactly as it should be printed, for example "Mr. and Mrs. Samuel Okafor" or "Dr. Grace Liu and Mr. Ben Takahashi". Formal titles go here, not in a separate column.
  3. Make the last three columns checkboxes (Insert → Checkbox). Tick a box when that mailing goes to the household.
  4. Format the Zip column as plain text (Format → Number → Plain text) so codes like 05401 keep their leading zero.

Share the sheet with whoever is collecting addresses from each side of the family. One shared list beats three versions in email.

2. Pick a label that looks formal

For invitations, a larger label reads as more deliberate than a small address label:

  • Avery 5163 (4" × 2", 10 per sheet) for a roomy, centered address.
  • Avery 5160 (2-5/8" × 1", 30 per sheet) for save-the-dates and thank-you cards, where a tidy small label is fine.
  • Clear or kraft labels in the same sizes use the same layout. Check the product number on the box.

Prefer no label at all? Print the address straight onto the envelope instead: see How to print envelopes from Google Sheets.

3. Style it for an invitation

In Spreadsheet Labels, open Text Style and:

  1. Choose Centered alignment, so each line sits in the middle of the label.
  2. Pick a serif font and a slightly larger size. Text that's too long for a line is made smaller automatically, so long names still fit.
  3. Optionally turn on Bold First Line so the names stand out.

Check every row in the preview before you print. Formal names are long, and the preview is where you catch a line that wraps.

4. Print one mailing at a time

  1. Open Rows to Print and choose Only rows where a column has a tick or text.
  2. Pick the column for this mailing, for example Invitation. Unticked rows are skipped.
  3. Print a test page on plain paper at Actual size (100%), hold it against the label sheet, then print the labels.

After the wedding, tick Thank You as gifts arrive and print the thank-you labels from the same list.

5. Return address labels

For the back flap, print a sheet of your return address on Avery 5167 (80 per sheet) or 5195 (60 per sheet). See Return address labels from Google Sheets.
